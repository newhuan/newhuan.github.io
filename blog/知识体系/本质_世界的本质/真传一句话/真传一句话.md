# 工程

工程的核心，是**将【质】上的复杂性问题，转换为【量】上时间和空间的成本问题**。

把复杂困难的单次计算，转换为加机器并行计算然后合并结果，这样问题就能够通过加机器解决。

把只能依赖稀缺的、需要高培养成本的高端人才才能解决的问题，转换为一般性人才合作就能解决的问题。

进一步就把主要矛盾转换为了如何治理巨大的量上的【**规模**】的问题，进而转换成对在大规模系统下，如果维持【**变更**】的可行性的治理问题。

**由质转量，治理规模，保持可变，就是工程要关注的核心事项。**

**能由质转量，就是工程可行，不能由质转量，就是工程不可行。能否由质转量，就是工程的边界。**



# 主观能动性

意思是：对事物发展作出**规划**，对其发展进行**预测**，制定一定对**目标**，并选择一定对实现目标的**途径和方式**（路线）。



# 目标

目标、目的，依靠**反馈**实现。反馈机制的建立，是实现目标最重要的基础。

人的认识认识到当前发展阶段的终态，就能意识到当前状态和发展终态的差距，从而可以按照一定的预先设想的蓝图即发展阶段的终态，来要求当前的输入，使系统的现实状态与发展终态之间的差距逐渐缩小为零，以实现这个发展阶段的终态。缩小差距的主要方式是制造出相应的反馈机制来调整当前的输入、行为。

**负反馈机制**：使系统通过自我调节而**保持**当前状态的**稳定**；

**正反馈**机制：致力于**打破系统的现存状态**，促使系统脱离原来的发展“轨迹”，使得系统以前表现的目的性追求变得难以达到，使系统开始追求一种新的目的性。

正负反馈总是**共存**。只有负反馈会消灭所有不稳定因素，进而失去发展能力；只有正反馈则所有稳定的倾向都会被破坏，永远无法进入稳定态，也不可能有真正的发展。发展是系统从一个稳定态，跃升到另一个稳定态，没有稳定态，就谈不上发展，也就不存在目标的达成。

对系统实施控制的目的，就是在一个事物可能性空间中进行有方向也包括有层次的可能的选择。

这种选择要在系统尚未发生重大的变更时就采取措施，从而实现有效的控制，而这种选择在系统内的涨落得以放大时即系统真正发生质的变化时实施，就往往是显得苍白无力，无法控制了。



# 共识

个人的成功，是通过让自己的行为，得到整个系统的认可，从而被整个系统接纳、放大实现的。

认可，实际就是让自己的行为成为系统更大范围内的共识，政治、管理等都是在引导、管理共识。

所以想成功，就得识别系统中有潜力的共识，在其尚未成为共识之前，开始实践，等共识被系统接纳、放大的时候，收获结果。



# 思维

**三类思维**：抽象（逻辑）思维、形象（直感）思维、灵感（顿悟）思维。

逻辑可以判断一个结论能否从前提推出，却不一定告诉人们“应该提出什么新问题”。新的科学构想往往先通过形象、模式、类比和整体直感形成，然后再由逻辑、数学和实验加以检验。因此，他把形象思维视为当时思维科学和人工智能研究的突破口。cas+1

用软件工程类比：

- 逻辑思维像逐层检查调用链、SQL和状态转换；
- 形象思维像先观察系统拓扑、监控曲线和故障模式，形成整体判断；
- 灵感像突然意识到几个看似无关的异常其实来自同一个底层机制；

钱学森认为，思维科学应当为人工智能提供理论基础，而计算机模拟又能成为研究思维的实验工具。这不是简单追求“机器代替人”，而是逐渐走向**人机结合、以人为主**：把人的经验和直觉、专家知识、数据、模型与计算能力综合起来。cernet.edu+2



# 创新

创新始于对**整体**的**直感**，成形于**逻辑分析**，完成于**计算、实验和实践检验**；复杂问题则需要个人、群体与计算机的系统协同。
