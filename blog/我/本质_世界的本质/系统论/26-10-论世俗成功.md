# 论世俗成功

**积累 -> 前沿 -> 预见 -> 自信、赌博 -> 分岔点、机遇 -> 被认可、接纳、放大  / 被拒绝、放弃、湮没 -> 跃迁 / 灭亡**

（孙宇晨、马斯克是这方面的代表，也是一种知行合一）

如何获取世俗意义上的成功呢？可以从协同学中的决定论、非决定论和分叉点的框架来说明。

决定论最朴素的理解是：**给定现在的一切状态和规律，未来就是唯一确定的。**

比如你扔一个球，只要知道它的位置、速度、空气阻力、重力等，理论上就能算出它下一秒在哪、最后落在哪。经典力学里常说的“拉普拉斯妖”就是这个意思：如果有一个妖怪知道宇宙中每个粒子的位置和速度，它就能推算出整个宇宙的过去和未来。

通俗说：**世界像一列按轨道运行的火车，看起来有很多选择，其实轨道早就决定了它会到哪。**

但要注意：决定论不等于“人能预测一切”。天气系统是决定论的，但极其敏感，初始条件差一点点，结果差很多，所以实际上预测不了太久。这叫**确定性混沌**：规律是确定的，但长期结果不可预测。

非决定论的基本意思是：**未来不是只有一条唯一的路，存在真正的随机性、多种可能，或者至少不能被唯一决定。**

它有几个层次，要分清：

- **本体论上的非决定论**：世界本身就有随机性。比如量子力学里，某个粒子衰变的时间不是提前完全写死的，只能说概率。
- **认识论上的不可预测**：世界可能背后有规律，但我们信息不够、系统太复杂，所以只能谈概率。比如掷骰子，严格说受力学决定，但实际我们只能算概率。
- **复杂系统里的多可能性**：系统在临界点附近有多个可能结局，微小扰动会决定走哪条路。

通俗说：**未来不是一条铁轨，而更像一张路网；有些路口，你只能知道“大概会往哪边走”，不能提前百分百断定。**

“分叉点”来自动力系统/协同学，英文叫 bifurcation，意思是：**当系统的某个条件慢慢变化到临界值时，系统原来的稳定状态失稳了，突然出现两个或多个新的可能稳定状态。这个临界点就是分叉点。**

最形象的比喻是**小球在山谷里**：

- 原来地形是一个“单谷”，小球不管怎么晃，最后都会滚到谷底。这个谷底是唯一稳定状态。
- 你慢慢转动一个“地形旋钮”，到了某个临界点，谷底中间鼓起一个小山包，单谷变成了“双谷”。
- 这时小球正好在中间尖点上，**极其微小的扰动**——风一吹、桌子一抖——就会让它滚进左边谷或右边谷。

这个“单谷变双谷”的临界参数，就是**分叉点**；左边谷和右边谷就是分叉后的两个可能去向。

再比如：

- **交通流**：车流密度逐渐增大，到某个临界点，原本畅通的车流可能突然变成拥堵；但具体哪一段先堵、堵成什么样，受微小扰动影响。
- **人群鼓掌**：大家本来乱拍，到某个临界点，可能突然同步成一种节奏；但同步到哪个节奏，受微小涨落影响。
- **人生选择**：平时积累决定你大概在什么位置，但某个关键路口，一个小机会、一句话、一次偶遇，可能把你推向完全不同的人生分支。

三者怎么放在一起理解？

可以这样看：

**分叉点之前：决定论色彩更强**

系统在某个稳定状态附近，扰动会被拉回来。像小球在谷底晃，最后还是会回到谷底。**大趋势比较确定。**

**分叉点附近：非决定论色彩最强**

系统旧状态失稳，多个新状态竞争，微小涨落会被放大。**“往哪边走”变得高度敏感，带有随机性/偶然性。**

**分叉点之后：又进入新的决定论阶段**

一旦系统进入左边谷或右边谷，它又会被新的稳定状态“吸住”，之后的行为又相对确定。**分叉点决定方向，分叉后规律支配路径。**

所以不是“决定论完全对”或“非决定论完全对”，而是：

> **系统大部分时候有稳定规律，但在临界分叉点附近，微小涨落会决定它进入哪条新路径；一旦选定路径，又会被新的规律支配。**

**最容易误解的地方**在于：

- **分叉点不等于“完全随机”**：分叉后的候选路径不是无限多，通常只有少数几个稳定分支。系统不是想变啥就变啥。
- **决定论不等于可预测**：混沌系统规律确定，但长期预测不了。
- **非决定论不等于“努力没用”**：分叉点前的大趋势、分叉点的选择、分叉后的路径依赖，都有规律可循。
- **分叉点不是每天都出现**：系统大部分时间在稳定态附近，只有参数逼近临界值时，分叉才显著。

于是，系统处于稳定态占绝对优势的状态的时候，决定论占主要优势，即大的规律是确定的，你给定的输入就会给你给定的输出，就是你要付出相应的努力，然后才有相应的回报。此时会给有一种感觉，就是宿命论，或者说天资决定先天的资质决定了一切，或者说，所谓的投胎时候没有的东西，这辈子都不会有。这样的说法，在决定论占优势的时候，其实是大概率成立的。

但是这个世界的分叉点很多，当社会或者说自己局部处于分叉点的时候，自己的选择、涨落、积累，自己的影响就有可能对系统的整体走向产生影响，一旦自己的到了局部系统乃至整个系统的认可，那么自己就可以在自己的微掌握跃升为系统的巨掌握的过程中，获得世俗上的成功。

而要想自己成为被系统选中的那个可能性，就要参考清末明初的各种救国尝试那样，一则不断追寻正确的路线，另一方面要在自己选定的路线上，经年累月的、艰苦卓绝的践行，争取越来越多的人的认可，也要接受自己的路线不被系统接受，成为众多尝试中不起眼的一个的可能性，现实是，选错往往才是最常见的情况。

认准自己看到的未来的方向，坚持下去，没有轻而易举的成功，也没有从此幸福下去的童话，只有不断斗争的过程，革命不是请客吃饭。
